


# Reflection 

Reflection is an (unfinished) experimental project combining prompt engineering, story telling and art.
It attempts to make uncomputable questions computable.

It answers to weakly defined queries like 

> How can I be a better person?

or

> What is the meaning of life?


## How it works

Words are precise, verifiable and therefore unsuitable to answer big questions in life. Reflection returns pictures. Art is neither right nor wrong.

If we want to answers questions we cannot, we can only let the user find their own way. Reflection merely provides the necessary tools for that. In its essence, this software is nothing more than a collection of magician tricks - shallow perceptional illusions merely mirroring the users own depth. Reflection uses our ability to find sense in meaningless patterns to blur the lines of external feedback and an own interpretation. On its own it cannot offer substance but only suggestive surface-level appearances. Rather then a harsh concrete it provides a soft vague that can be decoded by the users own experiences.

It is nothing more than a brainstorming-tool that risks getting too much credit for it. To make things a bit interesting I would like to call reflection a modern day oracle that rather than divine is engineered. At its core, this software-project is a mere bluff that overstretches engineering into the realm of art and story telling. Rather than build, we might try to construct. For the sake of entertainment, positive vibes and even solved use cases.
